# 视频图文纠错与主题分章验收

## 本次改动

- `source_grounding.py`：正文生成前，按 16 个转录片段一批输入原始文本、前后文和真实画面，提出最小纠错、主题边界和配图候选；另一次模型调用检查证据。检查也覆盖漏改的重要内容，不只检查已有修改。失败最多反馈修复一次，再失败终止。
- `contracts.py` / `quality.py`：原始 Transcript 不变；获准纠错独立存储。数字变更必须有附近画面及包含目标数字的可读引文，Core 记录帧 SHA256；普通编辑不能绕过数字、专有词、段落顺序校验。
- `video_service.py`：图文保真路径使用最多 192 个段内中点候选帧；校对候选不等于文章配图，最终最多 24 张。
- `faithful_edition_compiler.py` / `pipeline.py`：先校对再按主题分章，不再默认每 150 秒切断同一话题；编辑阶段也收到实际图片。正文、摘要分别复核，保留原有有界修复流程。
- `prompts.py` / `review.py`：分开不同标的及其收益、操作和条件；摘要从正文提炼，图注只描述可见证据。全文概览位于开头并携带来源引用；阅读版沿用章首、默认展开的 AI 摘要折叠块，不显示内部校对记录。
- `bundle_assembler.py`：修复“多/空账户比”等中文斜杠词语被误判为本地路径的导出阻塞；真实根路径、多级路径仍拦截。

按 openai-docs 技能参考官方 [Prompt engineering](https://developers.openai.com/api/docs/guides/prompt-engineering) 与 [Structured outputs](https://developers.openai.com/api/docs/guides/structured-outputs) 的输入/指令分离与结构化返回方式；没有更换模型、鉴权或 SDK。

2. 第二次生成通过内容复核但因“多/空账户比”触发隐私路径误判，未能导出：修复词语边界，不关闭隐私检查。

4. `job_01a0776a-5b8f-7cf6-ac5f-568f6d06e11d` 在源稿复核阶段停止：检查器要求本批修改属于相邻只读上下文的片段，并将原转录已有的“了”当作无依据新增。明确批次所有权和不改变主张/时态的语气词容忍边界后重新生成；没有放行失败结果。
5. `job_01a0776f-9aee-70eb-ad7b-6e9c584b1e63` 通过自动发布检查，8 章、16 图，88 条源稿校正的原文与真实帧 SHA256 全部核验一致。但人工放大检查发现：04:15 图注将 104.06 刻度误写成 104.36，正文“104左右”无误。新增确定性限制：图注不得引入所属正文段落未出现的数值；这样的可选配图不展示，不擅自猜改小数。提示同样要求描述正文已有的近似位置。随后重新生成，不手改原 Bundle。
6. `job_01a0777a-d909-77a2-ac85-3f6479249c4c` 在严格源稿解析时停止：模型返回的 `seg_000064.before` 漏掉原文末尾“多空笔”，违反完整原文匹配。对这类外部返回的契约错误复用同一个一次修复预算；修复必须重新通过全部证据规则和独立复核，再次错误仍停止。未放宽匹配规则。
